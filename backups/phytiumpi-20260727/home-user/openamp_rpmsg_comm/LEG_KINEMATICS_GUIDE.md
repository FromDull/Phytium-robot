# 对称并联腿运动学接入指南

本文记录四关节语义、五连杆坐标约定和下一阶段必须测量的数据。当前代码只提供经过
单元测试的正逆解函数，不会用未经确认的几何参数驱动舵机。

## 1. 关节语义

上层统一使用以下顺序：

```text
[右前, 右后, 左前, 左后]
```

有效角与舵机原始角的关系：

```text
右前有效角 = servo0 原始角
右后有效角 = 180 deg - servo1 原始角
左前有效角 = 180 deg - servo3 原始角
左后有效角 = servo2 原始角
```

因此稳定参考姿态：

```text
有效角 [45,45,45,45] deg
原始角 [45,135,45,135] deg
```

转换实现位于 `src/leg_joint_mapping.*`。语义命令为：

```bash
rprun leg-enable CONFIRM
rprun leg-joints <duration_ms> <右前> <右后> <左前> <左后>
```

MG996R 没有位置反馈。从核重启或执行 `servo-stop` 后，控制器不知道腿的实际姿态，状态为
`unarmed`，此时 `leg-joints` 会返回 `not-armed` 且不输出 PWM。必须支撑机器人，再执行
`leg-enable CONFIRM`。该命令不接受也不推断实际角度，只会输出固定安全参考命令：有效角
`[45,45,45,45]`、原始角 `[45,135,45,135]`。控制器随后保持 `starting` 约 3 秒，期间拒绝
轨迹命令。状态中的角度都是命令坐标，不是实测值；首次输出仍可能引起机械运动。

## 2. 五连杆模型

单侧腿使用两个固定髋轴和两条上连杆、两条下连杆。坐标原点位于前后髋轴中点：

- `x`：轮轴相对机身的前后支撑偏移，向前为正。
- `h`：髋轴中点到轮轴的垂直腿高，向下为正。
- 前髋轴坐标：`(+b/2, 0)`。
- 后髋轴坐标：`(-b/2, 0)`。
- `b`：前后髋轴中心距。
- `L1`：髋轴到膝关节的上连杆中心距。
- `L2`：膝关节到轮轴的下连杆中心距。

对任意一个髋轴 `p=(px,0)` 和目标轮轴 `f=(x,h)`：

```text
d = sqrt((x-px)^2 + h^2)
alpha = atan2(h, x-px)
beta = acos((L1^2 + d^2 - L2^2) / (2*L1*d))
joint_angle = alpha +/- beta
```

正负号决定膝关节解支。左右腿的机械结构对称，但前后支链的解支通常相反。代码通过
`front_elbow_branch`、`rear_elbow_branch` 和 `foot_branch` 显式保存解支，不在运行时猜测。
当前实机参考构型使用 `front=-1`、`rear=+1`、`foot=+1`。标定加载时必须执行一次
逆解到正解的往返检查，重建坐标误差超过 `0.1 mm` 时拒绝该配置。

## 3. 必须测量的数据

使用卡尺测量旋转中心之间的距离，不测外壳长度：

| 参数 | 含义 | 实测值 |
| --- | --- | --- |
| `b` | 同一侧前后髋轴中心距 | 90 mm |
| `L1` | 髋轴到膝轴中心距（大腿） | 85 mm |
| `L2` | 膝轴到轮轴中心距（小腿） | 145 mm |
| `h0` | 参考姿态下髋轴中点到轮轴高度 | 约 130 mm（钢卷尺粗测） |
| `x0` | 参考姿态下轮轴相对髋轴中点偏移 | 0 mm |

以上实测值和有效角 `45 deg` 的参考姿态已写入 `src/leg_robot_geometry.*`。在该几何下，
参考轮轴到单个髋轴的距离为约 `137.57 mm`，满足支链的几何可达范围 `60..230 mm`。

逆解得到的理论连杆绝对角约为前 `31.75 deg`、后 `148.25 deg`。它们不是舵机命令角；
代码使用参考姿态消除舵盘安装零偏，再输出有效角。以 `x=0` 为例，当前模型预测：

| 目标腿高 | 前有效角 | 后有效角 |
| --- | --- | --- |
| 120 mm | 40.72 deg | 40.72 deg |
| 130 mm | 45.00 deg | 45.00 deg |
| 140 mm | 49.31 deg | 49.31 deg |
| 150 mm | 53.70 deg | 53.70 deg |
| 160 mm | 58.25 deg | 58.25 deg |

这些值目前只用于离线计算，不能直接视为实机安全目标。

还需分别测量四个关节在连杆不干涉、舵机不堵转条件下的有效角最小值和最大值。
不能把舵机电气范围 `0..180 deg` 当作机械安全范围。

拍摄一张单侧腿正投影视图，标出前后方向、四个旋转中心和 45 度参考姿态，可用于确认
角度零点与解支符号。

## 4. 接入顺序

1. 支撑机器人并执行 `leg-enable CONFIRM`；等待约 3 秒并确认状态为 `idle` 后，才用
   `leg-joints` 做减小 2 度再返回参考位的悬空动作。
2. 测量四路机械安全角；几何参数 `b`、`L1`、`L2`、`x0`、`h0` 已录入。
3. 用实测参数离线验证 45 度参考姿态的正逆解往返误差。
4. 增加任务空间轨迹命令，让 `(x,h)` 在 50 Hz 下缓慢插值，并逐采样检查可达性和关节限位。
5. 支架悬空验证原地升降；左右目标完全相同，此时只观察 IMU roll，不闭环。
6. 确认高度轨迹后再加入左右高度差用于 roll 调平。
7. 最后才与轮式平衡同时运行，并在不同固定腿高分别重新建立或调度 LQR 参数。

任何一步出现连杆顶死、舵机啸叫、电源掉压或左右不同步，应立即切断舵机电源。
