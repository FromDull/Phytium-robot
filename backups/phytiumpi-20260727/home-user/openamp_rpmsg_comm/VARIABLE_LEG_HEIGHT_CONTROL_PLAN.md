# 可变腿高平衡控制实施方案

## 1. 当前结论

当前 4 状态 LQR 只对一个固定腿高有效。腿高变化会同时改变质心高度 `l`、俯仰惯量 `I`、车身质量分布以及舵机载荷，因此不能在现有增益下直接运动四个 MG996R 舵机。

MG996R 没有位置反馈。固件能知道的是 PWM 命令角度，不是关节实际角度和实际腿高。因此第一阶段只能做“命令姿态下的慢速准静态变高”，不能宣称已经实现腿高闭环或 VMC。

## 2. 控制分层

从核保持以下优先级：

1. 跌倒、CAN、IMU、轮速、控制超时保护。
2. 100 Hz 车身俯仰平衡 LQR。
3. 底盘线速度和角速度控制。
4. 低速腿高轨迹与横滚补偿。

Linux/ROS 2 只发送目标值和看门狗，不承担 100 Hz 稳定环。RPMsg 中断或 ROS 节点退出时，从核必须独立把速度目标降到零。

## 3. 变腿高前置标定

每个舵机都必须单独完成：

- 安装零偏；
- 原始 PWM 安全最小/最大角；
- 有效关节角方向；
- 45 度参考姿态下的实际腿高；
- 若可以，增加输出轴编码器或更换带反馈执行器。

现有安全参考仅表示原始命令 `45,135,45,135`，不能自动证明四个有效关节角都精确等于 45 度。

## 4. LQR 增益调度

完整装配到最终约 8 kg 后，在至少三个实测腿高建立模型节点，例如：

| 节点 | 实际腿高 | 需要重新测量/计算 |
| --- | --- | --- |
| 低 | `h_low` | `M, l, I, K_low` |
| 中 | `h_mid` | `M, l, I, K_mid` |
| 高 | `h_high` | `M, l, I, K_high` |

每个节点都按真实 100 Hz、单周期延迟、0.01 N*m 分辨率和实测力矩上限重新运行离散 LQR 仿真。运行时根据实际腿高或保守的命令腿高在线性插值 `K(h)`，禁止只缩放一组增益。

## 5. 从核状态机

建议新增腿高状态：

- `UNARMED`：PWM 关闭；
- `FIXED`：固定在已标定姿态，允许平衡；
- `TRANSITION`：低速同步变高；
- `HOLD`：到达目标后的固定姿态；
- `FAULT`：立即停止腿部轨迹，平衡环按故障策略处理。

进入 `TRANSITION` 的初始门槛：

- 车身平衡已激活；
- `|pitch| < 2 deg`、`|roll| < 2 deg`；
- `|linear speed| < 0.05 m/s`、角速度目标为零；
- 四个目标角均在逐轴标定安全范围；
- 单次腿高变化不超过 5 mm，初始速度不超过 5 mm/s。

过渡期间冻结新的底盘位移目标，保持零速度，四个舵机使用同一时间基准同步插值。任一姿态或速度门槛越界时停止腿部轨迹，不继续追赶目标。

## 6. 横滚控制边界

可以使用已融合的 IMU roll 做低带宽左右腿差动：

`delta_h = clamp(-(Kp_roll * roll + Kd_roll * roll_rate), delta_h_max)`

但 MG996R 没有反馈且机构互相约束，初始只允许极小修正，例如 `delta_h_max <= 2 mm`、带宽低于 2 Hz。俯仰平衡和轮子控制仍是主稳定通道，roll 补偿不能抢占快速姿态控制。

## 7. 验证顺序

1. 机器人悬空，逐轴短时 PWM 验证方向和限位。
2. 关闭轮电机，支撑机器人，验证四腿同步小步变高。
3. 固定三个离散腿高，分别重新标定机械零点并验证对应 LQR。
4. 保护绳下启用平衡，只在两个相邻节点间做 2 至 5 mm 变高。
5. 日志同时记录命令腿高、四轴命令角、pitch/roll、轮速、力矩、LQR 节点和插值系数。
6. 只有各固定节点和节点间过渡均稳定后，才开放 ROS 腿高命令。

## 8. 本轮实现范围

本轮先实现固定腿高下的底盘运动控制：从核接收线速度、角速度和看门狗，线速度进入 LQR 参考，角速度进入差动力矩控制；ROS 2 节点桥接 `/cmd_vel`、发布 `/odom` 和诊断。动态腿高保持禁用，直到上述标定和增益表完成。
